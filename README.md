# Futebol de Botão — TikTok LIVE

Projeto inicial do jogo de futebol de botão para TikTok LIVE.

## Render
Build Command:
`npm install`

Start Command:
`node server.js`

O Render fornece automaticamente a variável PORT.

## GitHub
Importante: envie os arquivos extraídos para a raiz do repositório. Não envie apenas o ZIP.

Arquivos principais:
- server.js
- package.json
- index.html
- game.js
- style.css
- audio/torcida.mp3
- audio/gol.mp3

A integração real com TikTok LIVE será adicionada nas próximas etapas.
